## 5. Justifications détaillées

### 5.1 `window.open` / `location.href` restants (lot 3)
Toutes les occurrences hors helper sont à URL constante ou à schéma fixé par le code : redirections littérales ou templates `/${locale}/…` (admin, auth, dashboards, confidentialité, `lib/coproprietaire/etat.ts`, `lib/document-sync.ts`, `hooks/useDashboardMessaging.ts`, `EcranInformations.tsx` avec langue typée) ; `mailto:` dont sujet, corps et destinataires passent par `encodeURIComponent` (DevisSection, FacturesSection, RapportTableRow, AppelsFondsSection, RapportMensuelSection, WalletConformite, QuoteRequestForm vers une adresse constante) ; `tel:` (SousTraitanceOffresSection) ; `sms:` (ParrainageSection, corps encodé) ; URL `blob:` créées localement pour l'aperçu PDF (`DevisFactureForm.tsx` côté artisan, `lib/pdf/devis-pdf-v3.ts` côté BTP : règle #1, non touchés ; `blob:` est de toute façon refusé par `toSafeUrl`) ; `lib/security/safe-url.ts` lui-même.

### 5.2 `dangerouslySetInnerHTML` laissés (lot 3)
85 occurrences classées : (a) 60 `<script type="application/ld+json">` construits depuis des données statiques du code (pages FR/PT/EN/ES/NL, `app/layout.tsx`, `InvestorPageTemplate`, `servico-distrito-partilhado`) ; `app/fr/artisan/[id]/layout.tsx` (données de la base) passait déjà par `serialiserJsonLd` (PR #537) ; (b) aucun JSON-LD à données utilisateur non sérialisé ; (c) 18 injections de Markdown IA désormais assainies par DOMPurify ; (d) constantes de confiance : `EmptyState.tsx` et `illustrations.ts` (SVG littéraux), `Empty.tsx` (`EMPTY_ILLUSTRATIONS`), `PublierMarcheClient.tsx` (4 chaînes littérales), `ConsentAnalytics.tsx` (identifiant GA constant), `QRCodeFracaoSection` (rectangles numériques), `DevisFactureForm.tsx` (SVG de signature construit localement) ; `ArquivoDigitalSection.tsx` utilisait déjà DOMPurify.

### 5.3 Chemins Storage (lot 2)
`grep -rn "supabaseAdmin.storage" app lib` : chaque argument de `upload`, `download`, `remove`, `createSignedUrl`, `getPublicUrl`, `list` est une valeur produite par `buildStoragePath` ou `assertStoragePath` (le seul appel indirect, `lib/tracking/session-suivi.ts`, reçoit un chemin construit par `buildStoragePath` dans ses deux appelants ; `app/api/setup-storage` ne manipule que des buckets).
